# 🎯 SEEK & SCAN - Interactive Cyber Tournament Platform

A high-tech web application and tournament management platform designed for interactive **Seek & Scan** events, campus hunts, and corporate challenges.

Faithfully crafted in a cyber-neon dark aesthetic matching the official tournament mission briefing.

---

## ⚡ Key Features

### 1. 🛡️ Anti-Cheat & Automatic Disqualification Engine
- **Fair-Play Proctoring**:
  * **Tab Switch / Backgrounding Detection**: Immediately detects if a player opens a new tab, minimizes the browser, or switches applications.
  * **"Circle to Search" & Screen Search Protection**: Catches window blur events generated by mobile assistant overlays (such as Android Circle to Search or iOS screenshot gestures).
  * **Shortcut & Clipboard Guard**: Blocks `Ctrl+C`, `Ctrl+V`, `Alt+Tab`, context menu right-click searches, and text selection on question cards.
  * **Automatic Lockout**: Triggers a high-alert red siren alarm, permanently locks the team session with an unclosable breach notification, logs the violation timestamp, and marks the team as **DISQUALIFIED** on the leaderboard.
  * **Admin Review & Override**: The Tournament Admin can inspect violation logs and reinstate teams if an accidental disruption occurred (e.g. an incoming cellular phone call).

### 2. 🎮 3-Round Interactive Gameplay
- **Rules (from Official Briefing)**:
  * Teams scan unique QR codes at physical stations.
  * Each QR unlocks **5 challenging questions**.
  * Solving all 5 questions reveals a **Secret Clue / Hint** to where the next QR code is physically hidden.
  * Teams locate the next station and enter the **Unlock Passcode** to advance.
  * The challenge has **3 rounds** (Cyber Perimeter, Cryptographic Maze, The Core Firewall).
  * The **fastest team** on the leaderboard wins!

### 3. 📱 In-App QR Scanner
- Real-time hardware camera viewfinder with mobile rear-camera priority (`facingMode: "environment"`).
- Camera switcher (Front/Back) and photo upload fallback.
- Testing simulator button for immediate testing in desktop browsers.

### 4. 👑 Master Admin Portal (For You Only)
- **Question & Clue Studio**:
  * Switch between Round 1, 2, and 3.
  * Add, edit, or delete questions (prompt, 4 choices, correct answer, points, hints).
  * Edit the **Location Clue / Hint** revealed upon solving all 5 questions.
  * Edit the **Secret Unlock Passcode** required to advance.
- **Physical QR Code Station Generator**:
  * Automatically renders vector QR codes for Stations 1, 2, and 3.
  * One-click **"Print Station Poster Sheet"** to print tournament-ready posters to stick on walls/campus locations!
- **Proctor & Team Control**:
  * Real-time cheat log monitor with instant "Reinstate" or "Disqualify" controls.
  * Team progress overview and tournament reset.

### 5. 🗄️ Supabase Cloud Integration & Dashboard
- Dedicated Supabase Hub inside the app.
- Simply paste your **Supabase URL** and **Anon Key** to connect to live PostgreSQL.
- Includes `supabase_schema.sql` with tables for `rounds`, `questions`, `teams`, `team_progress`, and `cheat_logs` with Row Level Security (RLS) policies and seed data.
- Works out-of-the-box in **Local Demo Mode** without requiring cloud setup up front!
